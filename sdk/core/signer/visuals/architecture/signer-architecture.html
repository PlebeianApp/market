signer — architecture

The module owns no environment. Everything it needs from the outside arrives through four injected ports — storage, transport, clock, crypto — and it never touches the browser, the relay, the extension or the OS keychain. That is measured, not claimed: zero occurrences of localStorage, sessionStorage, indexedDB, window., document., navigator., React, @nostr-dev-kit or the app's @/ alias anywhere in signer/ts/*.ts.

What the module owns

  • • The contract: thirteen session operations and one session-less entry, as plain values and typed errors
  • • The lanes: extension (NIP-07), nsec, ncryptsec (NIP-49), bunker:// and nostrconnect:// (NIP-46)
  • • The state machine: eight states, allowed transitions only, never active without a resolved identity
  • • The capability policy: nip04/nip44 present only when the signer has them and the composer allows them
  • • The record's format and its floor: PBKDF2-SHA256 600k → AES-GCM-256, 100k accepted when unlocking
  • • The refusal vocabulary: thirteen typed refusals over one base error, one per fail-closed path
  • • Its own dependency declaration, compiler configuration and test invocation — 9 implementation files, 1,997 lines

What it refuses to own

  • • No framework: no component library, no store library, no hook used as an interface
  • • No host storage or runtime: no browser key/value store, no IndexedDB, no browser global, no file path, no host timer, no host crypto call
  • • No relay I/O and no relay policy: no relay URLs, no kind filters, no publish semantics
  • • No host alias: every import is module-relative or a declared dependency
  • • No UI copy, no product questions, no marketplace event kinds — the signer does not know what it signs
  • • No raw private key on the public surface, except the explicit construct-on-key entry
  • • No environment at all. Storage, transport, timers and crypto primitives are ports; the extension is an argument, not a global

What is proven — and what is not

  • • Proven: 79 test cases in 5 files, all green; the module's own typecheck clean
  • • Proven: the isolation greps at 0 — no host storage, no browser global, no framework, no host alias
  • • Proven: 7 mutations, one per claimed invariant, each making its named test fail, each restored byte-for-byte and proved by hash
  • • Specified, not exercised: no relay was ever contacted — the NIP-46 lanes run against an in-process remote-signer emulator
  • • Specified, not exercised: no consumer, no host adapter, no second implementation
  • • Judged, not measured: that the record format matches the market's existing records — no such record was available to read here
  • • So: a first implementation with a hypothetical consumer. Nothing here proves the contract is usable by a real composer
