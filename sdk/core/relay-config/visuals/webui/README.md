# relay-config — visuals/webui

`index.html` is a single self-contained page (inline CSS and JS, no vendor script, no build step) that explains
the `relay-config` module in plain language. Open it directly from `file://`; it calls no backend.

It is **art, not evidence**. The authoritative documents are:

- `../relay-config.md` — the spec;
- `../ts/ts.md` — the implementation inventory;
- `../evidence/01-build-and-tests.txt` — the regenerated build, test, isolation and acceptance evidence
  (`bash ../evidence/run.sh`).

`SKILL.md` states what the page may and may not be quoted for.
